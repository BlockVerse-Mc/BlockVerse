# Contributing to BlockVerse

Thanks for helping! A few simple rules:

1. **Sign off your commits** (Developer Certificate of Origin): `git commit -s`. By signing off you confirm you
   wrote the change or have the right to submit it under the project's license (see LICENSING.md).
2. **Do not add Mojang's protocol JSON or code generated from it** to the repository (see LICENSING.md).
3. **No pirated or cracked game files, and no instructions for bypassing authentication or licensing.**
4. Keep changes small and tested: `cargo test --workspace`, `make -C native test`.
5. Be kind. Disagree with ideas, not people.
