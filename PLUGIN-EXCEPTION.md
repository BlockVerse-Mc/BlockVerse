# BlockVerse Plugin Exception (draft)

As an additional permission under section 7 of the GNU General Public License, version 3:

You may create, use, copy and distribute plugins that interact with BlockVerse **solely** through the BlockVerse Plugin ABI (the interface defined in `native/include/blockverse_plugin.h`) and the plugin SDK crates, under terms of your choice, including proprietary terms. Such a plugin is not considered a work based on BlockVerse merely because the server loads it at runtime.

This permission does not extend to modifications of BlockVerse itself, nor to code that uses internal BlockVerse interfaces other than the Plugin ABI.
